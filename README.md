# sangcnt.github.io

Sang Cao's personal portfolio for freelance clients, served by GitHub Pages at
https://sangcnt.github.io/. It moved here from `sangcaolabs.com/sang/` and
`sangcaolabs.com/projects/` on 2026-10-18, so that sangcaolabs.com is the Sang
Cao Labs company site only; those old URLs 301 here.

Plain HTML and one stylesheet, no build step. Pages deploys the `main` branch
root on every push.

- `index.html` — profile, stack, work, client feedback
- `projects/support-copilot/` — case study; the demo stays at
  `demo.sangcaolabs.com`

Client feedback quotes are verbatim from the Upwork profile (read 2026-09-08).
Do not reword them: an edited review is a made-up one.
